# ADR-001: حوكمة مرجع المشروع

**الحالة:** معتمد  
**الإصدار:** 1.0  
**التاريخ:** 2026-08-23

## القرار

يُعتمد `MASTER-PROJECT-VISION v0.2` و`COVERAGE_AUDIT_137_396` مرجعين وظيفيين للمشروع. لا يبدأ تنفيذ فرع جديد ولا يتغير فرع قائم قبل توثيق نطاقه، وقراراته، ومخاطره، واختبارات قبوله في ملفات المشروع.

## الأثر

كل ميزة برمجية ترتبط بمعرّف من جدول التغطية، وقرار معماري، وحالة اختبار قبول. أي تغيير لاحق يُسجل في ADR جديد ولا يكتب فوق القرار السابق من دون تاريخ وأثر واضحين.

## قواعد التنفيذ

| القاعدة | التطبيق |
|---|---|
| مصدر الحقيقة | لا تعتمد المحادثة وحدها كتعليمات تنفيذ؛ يُستخدم المرجع المعزول والإصدار المحدد. |
| الفرع الواحد | لا يُدمج فرع جديد قبل نجاح اختبارات قبول الفرع الحالي. |
| التحقق الخارجي | تكاملات OneDrive وMeta وWhatsApp وTikTok وشركة التوصيل تُعامل كافتراضات حتى تنجح في اختبار حي. |
| البيانات الحساسة | حماية التكلفة والهامش شرط تصميم واختبار، وليست قرار واجهة فقط. |
