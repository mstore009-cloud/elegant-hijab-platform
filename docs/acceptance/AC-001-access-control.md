# AC-001: قبول نواة الهوية والصلاحيات

## النطاق

يوثق هذا الاختبار نواة الموظفين والصلاحيات الدقيقة وحجب البيانات المالية الحساسة.

| السيناريو | النتيجة المقبولة |
|---|---|
| موظف منتجات يملك إضافة منتج فقط | يستطيع إنشاء المنتج ولا يستطيع الحذف أو تعديل التسعير أو رؤية التكلفة. |
| موظف طلبات يملك رفع التوصيل فقط | يستطيع تحديث خطوة الرفع ولا يستطيع تعديل المنتج أو رؤية بياناته المالية. |
| مدير يملك صلاحية مالية حساسة | يرى التكلفة والهامش وصافي الربح عند توفر البيانات. |
| مستخدم غير مخول يستدعي الواجهة الخلفية مباشرة | يتلقى رفض صلاحية؛ لا تعود حقول التكلفة أو الهامش في الاستجابة. |
| إزالة صلاحية من موظف | يسقط الوصول فورًا في الواجهة والواجهة الخلفية. |

## معايير النجاح

لا تُغلق الشريحة إلا بعد تحقق اختبارات الوحدات من كل سيناريو، وظهور نتيجة رفض واضحة عند استخدام صلاحية غير ممنوحة، وعدم تسريب حقل مالي حساس في أي استجابة غير مخولة.
