# AC-002: قبول المنتجات والمتغيرات ومسار الإدخال

| السيناريو | النتيجة المقبولة |
|---|---|
| منتج متعدد الألوان | يمكن إنشاء منتج أب مع عشرات أو مئات الألوان، ولكل لون مخزون مستقل. |
| لون وقياس | يمكن إنشاء تركيبات لون وقياس منفصلة بلا تكرار. |
| مسودة ناقصة | يبقى المنتج داخليًا في مسودة أو «يحتاج مراجعة» ولا يظهر جاهزًا للنشر. |
| موظف غير مالي | يرى سعر البيع فقط، ولا تصل تكلفة المنتج أو هامشه في استجابة الخادم. |
| تحديث مخزون | يتغير مخزون متغير واحد ولا تتأثر بقية الألوان أو القياسات. |
| OneDrive غير متاح | يسجل فشل الاختبار ويستمر الإدخال اليدوي عبر مهمة مستقلة دون تغيير المنتج أو المتغيرات. |

> لا يكتمل مسار OneDrive قبل اختبار مصادقة حقيقي وقراءة مجلد منتج فعلي؛ ما سبق يثبت البديل الآمن ونموذج البيانات فقط.
